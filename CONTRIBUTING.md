# Contributing

Create a virtual environment, install `.[dev]`, and run `./scripts/check.sh`. Contributions must
preserve separate MNCS/MNCDS statuses, explicit `UNKNOWN`, no-shell execution, authority
boundaries, append-only history, and non-normative positioning. Changes to control flow, data
flow, authorization, validation, error handling, or cleanup require an appropriate declared
provider when structural evidence is needed. Use the same provider and method before and after
when comparative evidence is claimed. Joern is optional. Source reading, grep, and line counts
do not replace an unavailable capability; preserve `UNKNOWN` or report a blocker.

Do not submit secrets, private evidence, protected datasets, or evidence you cannot redistribute.
By contributing intentionally, you agree to license the contribution under Apache-2.0.
